## Key Decisions Awaiting Your Input

1. **CMS choice** — Sanity.io is proposed. Would the practice manager prefer a simpler option (e.g., Notion-as-CMS, or a custom ENGO.STUD admin panel)?
2. **Booking flow depth** — MVP uses an async request form (email notification). Do you need real-time slot selection (calendar grid) for MVP, or is that confirmed as MVP+1?
3. **Branding palette** — The frosted-glass dark-first aesthetic follows ENGO.STUD standards. Should Dentish use a **light-mode-first** aesthetic instead (more typical for healthcare/dental)?
